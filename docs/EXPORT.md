# Using assets in other projects

There are three ways in, from easiest to most flexible.

## 1. GLB files (any engine, any AI project)
- In the viewer, open an asset, set its options (colours, contents, job, gate state…) and **New look** if it has one, then press **Export GLB**. The file is named `<id>.glb` (`<id>-<seed>.glb` for a specific look).
- From the browser console or a script on the page:
  ```js
  await AssetForge.download('vx-barn');
  await AssetForge.download('an-horse', {options:{coat:'#26242a', pattern:'spots'}});
  await AssetForge.download('villager', {seed:7, options:{job:'blacksmith'}});
  const buf = await AssetForge.exportGLB('it-c-barrel', {options:{contents:'wine'}}); // ArrayBuffer
  ```
- **Contents of a GLB:**
  - Meshes with embedded pixel textures (nearest-filter look; set nearest filtering in your engine).
  - Point lights (as `KHR_lights_punctual`).
  - **All animation clips** for villagers and animals (named `Idle`, `Walk`, `Run`, `Graze`, …).
  - Units are metres, +Y is up, and the front faces +Z.
- **Not included:** procedural motion (turning sails and wheels, water waves, flame flicker, gate animation, scene agents). Scenes export as static geometry.

## 2. The JavaScript library (three.js r128 projects)
Load three r128, then `dist/asset-forge-lib.js` (run `npm run build` first):
```html
<script src="vendor/three.min.js"></script>
<script src="vendor/GLTFExporter.js"></script>   <!-- only needed for GLB export -->
<script src="dist/asset-forge-lib.js"></script>
<script>
  const barn = AssetForge.build('vx-barn');                 // THREE.Group, metres, front +Z
  scene.add(barn);
  const smith = AssetForge.build('villager', {seed:4, options:{job:'blacksmith'}});
  const mixer = new THREE.AnimationMixer(smith);
  mixer.clipAction(smith.userData.clips.find(c => c.name === 'Hammering')).play();
  // each frame: mixer.update(dt); smith.userData.post && smith.userData.post();
</script>
```
- `AssetForge.list()` returns ids, names, folders, kinds, options (with choices and defaults), and whether the asset has random looks.
- Lights are in `root.userData.lights`; set their intensity to suit your scene.

## 3. The catalog (for search and for AI tools)
`dist/catalog.json` (machine-readable) and `docs/ASSET_CATALOG.md` (human-readable) list every asset with its folder, options and description. Both are regenerated by `npm run catalog` and automatically by the dev server on every save. Search by id prefix:

| prefix | kind |
|---|---|
| `vx-` | buildings |
| `fn-` | fences |
| `cp-` | outlaw camp |
| `an-` | animals |
| `ol-` | outlaws |
| `villager*` | villagers |
| `it-` | items |
| `env-` | environment |
| `tr-` | terrain tiles |
| `wl-` | wasteland kit (modular, 4 m grid; see WASTELAND.md) |
| `sc-` | scenes |
